# web/

Веб-панель Mirocraft — SPA на React + Vite + Tailwind, клиент REST API.

Пока заглушка: каркас появится в задаче 3.1 (см. `docs/ROADMAP.md`).

## Что здесь будет

```
web/
  index.html          инлайн-скрипт применения темы до первого рендера
  src/
    themes/
      tokens.css      контракт CSS-переменных (объявление + дефолты)
      dark.css        встроенные темы — по одному файлу на тему
      light.css
      midnight.css
      grass.css
      nether.css
      index.ts        реестр тем с метаданными
    ...
  dist/               прод-сборка, встраивается в бинарник через go:embed
```

## Правила

Цвета — только через CSS-переменные, ни одного литерала в компонентах;
новая тема = один файл; каждая тема проходит проверку контраста WCAG AA.
Полностью — в `CLAUDE.md`, раздел «Темы оформления», и в
`docs/ARCHITECTURE.md`, раздел «Веб-панель → Темы».

`dist/` в гит не коммитится (см. `.gitignore`) — её собирает CI.
